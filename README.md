# 🌍 Сайт для подсчета твоего вклада в загрязнение планеты

## 📌 О проекте

Веб-сайт, посвященный проблеме **глобального потепления**. При нажатии на кнопку пользователю выдается несколько случайных фактов о том, какие повседневные действия вредят планете и загрязняют окружающую среду.

Проект помогает задуматься о личном вкладе каждого человека в загрязнение планеты и показывает, что даже привычные бытовые действия имеют экологический след.

## 🎯 Цель проекта

- Привлечь внимание к проблеме глобального потепления
- Показать, как повседневные привычки влияют на экологию
- Побудить пользователей к более осознанному потреблению

## ⚙️ Как это работает

1. Пользователь открывает сайт
2. Нажимает кнопку
3. Сайт случайным образом выбирает и показывает несколько фактов о повседневных действиях, которые вредят планете
